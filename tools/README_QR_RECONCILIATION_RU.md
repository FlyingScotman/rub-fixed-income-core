# Диагностика сверки облигаций QR / Calypso

Скрипт `qr_bond_reconciliation_probe.py` собирает воспроизводимый ZIP с исходными объектами и результатами расчётов для 30 заданных строк WAP. Он рассчитан на Windows-машину с установленными `vtb_qr`, `rubik_api` и `calypso_framework`; дополнительные Python-пакеты не нужны.

`rubik_api` используется только для инициализации и загрузки диапазонов кривых (`load`, `RBK_ObjectsLoad`). Загрузка и сохранение QR-объектов, преобразования, расчёты и инспекция выполняются через `vtb_qr`. Исходные байты продукта Calypso сохраняются отдельно от созданного через `vtb_qr.SaveObject` файла `xml.zip`.

## Запуск в `cmd.exe`

Скопируйте **только** `qr_bond_reconciliation_probe.py` в закрытый рабочий каталог. В том же окне `cmd.exe` задайте учётные данные и выполните одной командой:

```bat
set CALYPSO_LOGIN=ВАШ_ЛОГИН
set CALYPSO_PASSWORD=ВАШ_ПАРОЛЬ
python qr_bond_reconciliation_probe.py
```

Учётные данные читаются только из этих двух переменных окружения и не записываются в отчёт. Не передавайте их через аргументы командной строки.

Снимок кривых по умолчанию — **03.09.2026**. Расчёты выполняются на **03.09.2026**, **04.09.2026** (дата сделки) и **07.09.2026** (вероятная дата расчётов T+1 с учётом рабочего дня). Это позволяет отличить расхождение снимка рынка от эффекта даты расчёта.

После выполнения верните файл `qr_reconciliation_20260903.zip`, находящийся рядом с одноимённым каталогом. Даже при частичной или аварийной обработке скрипт старается сохранить уже собранные данные и создать архив. Статус `complete` присваивается бумаге только при успешных конечных прямых расчётах доходности и Z-spread к RUONIA на всех заданных датах; иначе результат помечается `partial` или `error`. Код возврата `1` означает неполный результат, `2` — ошибку упаковки.

## Параметры

```bat
python qr_bond_reconciliation_probe.py --curve-date 2026-09-03 --calculation-dates 2026-09-03,2026-09-04,2026-09-07 --publication "CALYPSO LIVE DATA" --output-dir qr_reconciliation_20260903 --isin RU000A10C6L5 --isin RU000A10F7L0
```

`--isin` можно повторять либо перечислять значения через запятую. При отсутствии фильтра обрабатываются все 30 бумаг. Даты задаются в формате `ГГГГ-ММ-ДД`.

## Конфиденциальность

ZIP содержит приватные сериализованные продукты Calypso (`products/raw`), сохранённые объекты Rubik, характеристики инструментов, денежные потоки и рыночные кривые. Не открывайте бинарные файлы в консоли, не публикуйте архив и не отправляйте его вне разрешённого защищённого канала. Перед передачей проверьте правила работы с торговыми и клиентскими данными вашего подразделения. Сам скрипт не печатает сериализованные данные, пароль или логин и не выводит traceback.
